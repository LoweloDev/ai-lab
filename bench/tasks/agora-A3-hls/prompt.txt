Feature request for this Go monorepo: LiveKit egress can also emit WebM media segments, but the HLS delivery layer does not know the .webm extension yet. Teach the delivery layer that `.webm` is an immutable media segment served with content type `video/webm`. Be careful: the backend's cache policy is not the only place with an opinion about segment extensions — the proxy configuration in front of the origin bucket must agree, and there is a test that enforces this coupling. Verify with `cd agora-backend && go test ./internal/livehls/ -count=1`. Do not edit any test files.
